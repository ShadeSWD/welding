# welding — Сварка судовых конструкций

Статический учебный сайт (чистые HTML/CSS/JS, без сборки): курс теории сварки
судовых конструкций и живые инженерные расчёты — режимы сварки, свариваемость
сталей с подогревом по EN 1011-2, расход сварочных материалов, сварочные
деформации.

**Прод:** https://shadeswd.duckdns.org/welding/

## О сайте

Пять глав теории (дуга и источники нагрева, способы сварки, соединения и швы,
металлургия сварки и зона термического влияния, дефекты и неразрушающий
контроль) и четыре расчётные страницы, где каждая величина считается по шагам:
«формула = подстановка = результат». Все схемы — векторные, перестраиваются
вместе с исходными данными.

Формулы сверены с первоисточниками: ГОСТ 5264-80 и 14771-76 (типы соединений и
конструктивные элементы), ГОСТ 2.312-72 (обозначения на чертежах),
ГОСТ 30242-97 (классификация дефектов), ГОСТ 7512-82, 18442-80 и 21105-87
(неразрушающий контроль), BS EN 1011-1 и EN 1011-2 (погонная энергия,
углеродные эквиваленты, расчёт температуры подогрева по методу B),
Правила РМРС части XIII и XIV, ОСТ 5.9092-91. Где утверждение подтвердить не
удалось, на странице стоит явная пометка, а параметр сделан редактируемым.

## Содержание

- `site/` — сам сайт
  - `index.html` — обзор курса и навигация
  - `theory.html` — оглавление теоретического курса
  - `t-arc.html` — сварочная дуга, источники нагрева, погонная энергия
  - `t-processes.html` — способы сварки: ручная дуговая, в защитных газах,
    под флюсом; области применения в судостроении
  - `t-joints.html` — соединения, швы, разделка кромок, обозначения по ГОСТ
  - `t-metallurgy.html` — металлургия сварки, зона термического влияния,
    структуры и скорость охлаждения
  - `t-defects.html` — дефекты сварных соединений и неразрушающий контроль
  - `modes.html` — подбор режима сварки: диаметр, ток, напряжение, скорость,
    плотность тока, погонная энергия, число проходов
  - `weldability.html` — свариваемость: CEV, CET, Pcm, углеродный эквивалент
    ГОСТ 27772, пределы РМРС по категории и толщине, температура подогрева по
    EN 1011-2, скорость охлаждения и время Δt₈/₅ по Рыкалину
  - `consumption.html` — расход сварочных материалов: площадь наплавки, масса
    наплавленного металла, электроды, проволока, защитный газ, флюс, время и
    электроэнергия
  - `distortion.html` — сварочные деформации: усадочная сила, продольное
    укорочение, прогиб, угловая деформация, проверки допустимости
  - `sources.html` — источники с пометками о степени подтверждения
  - `assets/` — `style.css`, `site.js` и расчётные библиотеки `wcalc.js`,
    `modes.js`, `weldability.js`, `consumption.js`, `distortion.js`
- `deploy/` — `docker-compose.yml` (nginx:alpine, порт 8074) и конфигурация nginx
- `tests/` — переносимый набор тестов целостности сайта (pytest)

## Запуск

```bash
cd deploy && docker compose up -d      # http://127.0.0.1:8074/
python3 -m pytest tests/ -v            # тесты целостности
```

Сайт входит в кластер учебных сайтов: общий подвал, словарь терминов и
рендер формул подключаются nginx-ом на уровне домена.
